# Screenshot Checklist for Final Report

Please capture the following 10 screenshots of your local environment and attach them to your final project report to serve as visual evidence of the successful pipeline implementation.

- [ ] **Screenshot 1: Project Folder / Source Structure**
  - Open VS Code (or your IDE) and expand the `dags/`, `src/`, `dashboard/`, and `data/` folders in the explorer pane. Capture the layout.

- [ ] **Screenshot 2: Raw Data Landing Files**
  - Show the contents of the `data/raw/pollution/` and `data/raw/weather/` directories, proving the JSON files were successfully downloaded.

- [ ] **Screenshot 3: Airflow DAG Overview**
  - Open the Airflow Web UI (if running) or show the terminal output of the DAG structure. The screenshot should clearly display the `aqi_data_pipeline` and its 6 sequential tasks.

- [ ] **Screenshot 4: Airflow Task Execution (Successful Tasks)**
  - Show the terminal output from running `airflow dags test aqi_data_pipeline ...`. The terminal should display the logs ending with successful task completion for each step.

- [ ] **Screenshot 5: PostgreSQL Tables / Sample Records**
  - Open pgAdmin, DBeaver, or psql. Run a `SELECT * FROM hourly_air_quality LIMIT 10;` query and capture the resulting rows showing actual populated data.

- [ ] **Screenshot 6: Database Verification / Row Counts**
  - Take a screenshot of the terminal output generated by running `python src/database/verify_db.py`. It must clearly show the "DATABASE VERIFICATION REPORT" with the exact counts and constraints passing.

- [ ] **Screenshot 7: Streamlit Dashboard — Overall View**
  - Capture the top half of the browser window running `http://localhost:8501`. Show the title, sidebar filters, and the Top KPI metric cards.

- [ ] **Screenshot 8: Dashboard with City/Station Filters**
  - Open the Sidebar dropdowns. Capture a screenshot proving that multiple cities (e.g., Delhi, Kolkata, Mumbai, Chennai) and specific stations are successfully populated in the filter UI.

- [ ] **Screenshot 9: AQI Trend / City Comparison**
  - Capture the Streamlit charts for "1. AQI Trend" and "2. Comparisons" showing the Line and Bar charts rendering successfully based on the selected city.

- [ ] **Screenshot 10: Pollutant/Weather Analysis**
  - Scroll down and capture the "PM2.5 vs NO2" scatter plot and the "Weather Relationships" scatter plot to prove analytical combinations are functioning.
